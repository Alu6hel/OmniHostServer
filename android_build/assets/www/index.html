Wireless Storage & FTP Sync

Mount your phone storage wirelessly on any computer without USB cables:

FTP Address: ftp://192.168.x.x:2121
WebDAV Drive: http://192.168.x.x:8090/webdav
Credentials: Anonymous (Read / Write Access)
Root Directory: /sdcard/Download/omnihost_sites
How to connect from your PC / Mac:
  1. Ensure your computer is connected to the same WiFi or Hotspot.
  2. Open Windows File Explorer (or Mac Finder → Connect to Server).
  3. Enter ftp://192.168.x.x:2121 or http://192.168.x.x:8090/webdav.
  4. Drag and drop files, photos, or HTML code directly to upload wirelessly!
