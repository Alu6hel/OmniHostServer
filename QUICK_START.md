# ⚡ OmniHost Pro — 60-Second Quick Start

1. **Launch**:
   - Double-click `OmniHostServer.exe`
2. **Local Website**:
   - Visit: `http://localhost:8090`
3. **Wireless Phone Uploads (WiFi FTP)**:
   - On your phone's File Manager, connect to: `ftp://<LAN_IP>:2121`
   - Upload images, files, or updated HTML wirelessly!
4. **Public HTTPS Link (Masked Home IP)**:
   - Click "Start Cloudflare Tunnel"
   - Share your public `https://...trycloudflare.com` link safely!
